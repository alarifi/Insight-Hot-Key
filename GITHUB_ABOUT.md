## 2. خطوات النشر السريع عبر GitHub Desktop
1. افتح برنامج **GitHub Desktop**.
2. من القائمة العلوية اضغط على **File** ثم اختر **Add Local Repository...** (أو اضغط `Ctrl + O`).
3. اختر مسار هذا المجلد:
   `E:\PortableApps\insight software\Insight Hot Key\Insight Hot Key\output\github`
4. إذا لم يكن المستودع مهيأً، سيقترح GitHub Desktop الضغط على **Create a repository** أو تم تهيئته عبر Git.
5. اضغط على زر **Publish repository** في الأعلى لنقل ورفع المشروع مباشرة إلى حسابك على GitHub!

# Insight Hot Key v1.0.0 Pro ⚡
We are excited to announce the official release of **Insight Hot Key**, a modern, lightweight, and ultra-fast hotkey launcher engineered in C# .NET 8 / WPF for Windows 10 and 11.

### 🌟 Key Features:
- ⚡ **Global Master Hotkey**: Instant launcher access anytime using `ALT + Space`.
- 🔄 **Smart Window Switching**: Brings running application windows to the front instead of opening duplicate processes.
- 🛡️ **Core Windows Hotkey Guard**: Protects system shortcuts (`Ctrl+C`, `Ctrl+V`, `Ctrl+S`, `Alt+F4`, etc.) from accidental hijacking.
- 🌐 **100% Pure Bilingual UI**: Pure Arabic (`العربية`) and Pure English (`English`) with zero untranslated text.
- 📊 **Dynamic Slot Rows**: Unlimited rows with smooth dark scrolling; auto-expands when dragging items.
- 📁 **Multi-Type Actions**: Applications, Folders, Websites, Snippets, and System Commands with glowing pill badges.
- 💾 **100% Portable & Offline**: Clean local JSON storage without registry modifications or telemetry.
